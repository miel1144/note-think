# note-think

App móvil de notas **local-first** (Android primero, iOS después).
Construida con Flutter + Neumorfismo.

## Características

- Editor rico (negritas, listas, imágenes, links)
- Notas con color identificador (esquina superior derecha)
- Búsqueda full-text local
- Papeleras con recuperación
- Modo oscuro
- Export a PDF y ZIP
- Bloqueo con biometría
- Recordatorios locales
- Widget Android

## Stack

Flutter · Riverpod · go_router · Isar · flutter_neumorphic · flutter_quill
